# koreaneducationsystem
A comprehensive interactive web portal exploring South Korea's education system (한국의 교육 제도), featuring school stages, curriculum, Suneung (CSAT), cultural school life, and comparisons with the Indian education system.

## 🌟 Features
- **Education Stages**: Kindergarten, Elementary, Middle School, High School, and SKY Universities.
- **Suneung (CSAT) Guide**: Full breakdown of the test day, timetable, security, and cultural traditions.
- **School Life & Culture**: Uniforms, after-school academies (*Hagwons*), night study (*Yaja*), and classroom etiquette.
- **Comparative Analysis**: In-depth comparison between the South Korean and Indian educational models.
- **Interactive Quiz**: 5-question bilingual knowledge test.
- **Bilingual Interface**: Seamless instant English / Korean (한국어) translation toggle.

## 🚀 Live Demo & Usage
Open `index.html` directly in any web browser or serve locally:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
